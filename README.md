# 바자회 달란트 UI 시안

참고 서비스와 독립된 빌드 없는 HTML/CSS/JavaScript 시안입니다.
외부 라이브러리, 폰트 다운로드, 지갑 연동, 카메라, RPC, 실제 송금을 사용하지 않습니다.

## 로컬 실행

상위 `mst-bazaar` 디렉터리에서:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

<http://localhost:8000/bazaar-ui/>에 접속합니다.
이 디렉터리만 별도로 정적 호스팅해도 작동합니다.

## 미리보기

- 사용자 화면은 기본 7개로 줄였습니다. 테스트 패널은 URL에 `?preview=1`을 붙여 엽니다.
- PC: 왼쪽 기본 목록에서 화면을 고릅니다. 예외 상황은 ‘다른 상황 테스트’를 펼칩니다.
- 모바일: 상단 ‘미리볼 화면’ 선택 상자를 사용합니다.
- 준비 화면은 진입 즉시 요청 대기로 바뀝니다. 테스트 패널의 **Confirm 누름**으로 승인을 재현합니다.
- 연결 → 추가/전환 → 잔액 조회까지 이어집니다. 사용자 화면에는 별도 승인 버튼이 없습니다.
- **취소함**, **확인 창이 뜨지 않음**을 누르거나 8초간 응답이 없으면 재요청 버튼이 나타납니다.
- 이미 대기 중인 요청은 중복 생성하지 않습니다. 실제 provider 요청은 보내지 않는 시뮬레이션입니다.
- ‘다음 단계로 보기’는 충전·결제 결과를 재현합니다. 화살표는 테스트 상황을 순서대로 탐색합니다.
- 서비스 화면의 버튼은 실제 외부 동작 대신 다음 예시 상태로 이동합니다.
- 주소 QR은 스캔할 수 없는 장식용 샘플입니다.
- `#opening`, `#home`, `#pay`, `#payment-success`처럼 URL 해시로 상태를 직접 열 수 있습니다.
- ‘결제 전에 지갑 준비’에서 시작하면 준비 완료 후 결제 화면으로 복귀합니다.

잔고, 환율, 10% 충전 보너스, 네트워크 이름, 부스 이름 및 결제 결과는 시안용 예시입니다.
실제 구현 시 행사 정책과 운영 설정을 확정해야 합니다.
